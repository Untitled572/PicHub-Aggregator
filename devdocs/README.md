# PicHub-Aggregator Development Documents

本目录包含面向 AI 辅助开发的架构设计文档与实现规范，由 `AGENTS.md` 引导加载。

这些文件用于帮助 AI 编码助手理解项目设计、数据流、标签匹配规则等细节，**与终端用户无关**。
日常使用本应用的用户可忽略此目录，参考 `README.md` 和 `docs/` 下的文档即可。

| 文件 | 内容 |
|---|---|
| `ARCHITECTURE.md` | 整体架构与技术栈概述 |
| `IMAGE_FLOW.md` | 图片请求生命周期与抓取数据流 |
| `TAG_MATCH_RULES.md` | 标签匹配规则定义与 91 组测试用例 |
| `PRD.md` | 产品需求文档 |
| `DEVELOPMENT_PLAN.md` | 开发计划 |
